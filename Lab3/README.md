# Assignment 3: Your First HTML Page

**Course:** HTML and CSS Introduction Lab (BCS352)  
**Institution:** Invertis University, Bareilly  
**Degree:** B.Tech CSE - Second Year  

---

### Aim
Write a first HTML page with a title, headings and a paragraph, and format some text.

---

### Tasks
1. Create first.html with the document structure, the title My First Page, and one h1 heading: Hello, I am Asha. Open it in a browser.
2. Create headings.html with an h1 heading, an h2 heading, an h3 heading and one paragraph. Write any text for them.
3. Create text-format.html with two paragraphs of any text. Use strong and em on one word each, and put a line break inside one paragraph.

---

### Sample Expected Output
The browser tab says My First Page. The page shows one large heading. Three headings, each smaller than the one above, and a paragraph under them. The strong and em words look bold and italic. The line break starts a new line inside the paragraph.

---

### Submission Guidelines
**Submit:** One .html file per task (and a .css file where used) and a screenshot of the page.  
*Remember to include your Name, Roll Number, and Assignment Number (3) at the top of each file.*
