# Assignment 15: Responsive Pages with Media Queries

**Course:** HTML and CSS Introduction Lab (BCS352)  
**Institution:** Invertis University, Bareilly  
**Degree:** B.Tech CSE - Second Year  

---

### Aim
Use a media query to change a layout, make a picture scale with its box, and set text sizes with rem units.

---

### Tasks
1. Create mobile-first.html with the viewport meta tag in the head, and a div with the class cards holding two cards (class card), each with an h2 heading and a paragraph. Write base styles for phones, then add a media query for screens 600px wide and up that shows the cards side by side.
2. Create responsive-image.html with a heading and one picture from the images folder. Set the picture to max-width 100% and height auto, so it shrinks to fit a narrow window. Use the file name your instructor gives you.
3. Create responsive-text.html with an h1 heading and a paragraph. Set the body font size to 1rem and the h1 to 1.5rem. Add a media query for screens 600px wide and up that sets the h1 to 2.5rem.

---

### Sample Expected Output
On a phone the cards stack. At 600px and up they sit two per row. On a narrow window the picture shrinks to fit. On a wide window it keeps its own size. The heading is larger when the window is 600px wide or more.
