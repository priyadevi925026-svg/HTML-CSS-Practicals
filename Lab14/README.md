# Assignment 14: CSS Grid Layouts

**Course:** HTML and CSS Introduction Lab (BCS352)  
**Institution:** Invertis University, Bareilly  
**Degree:** B.Tech CSE - Second Year  

---

### Aim
Make a grid with equal columns, a responsive gallery and a layout with named areas.

---

### Tasks
1. Create grid-first.html with six boxes (div elements) showing the numbers 1 to 6, in a grid of three equal columns (fr units) with a gap of 12px.
2. Create gallery.html with an h1 heading Club Photo Gallery and six boxes labelled Photo 1 to Photo 6. Use grid-template-columns with repeat(auto-fill, minmax(150px, 1fr)) and a gap of 10px.
3. Create dashboard-areas.html with a grid of two columns, 200px and 1fr. Use grid-template-areas to place a header and a footer across both columns, a sidebar on the left and a main area on the right.

---

### Sample Expected Output
Six boxes in two rows of three, with small gaps. As the window gets wider, more boxes fit in each row. A header across the top, a sidebar on the left, a main area on the right and a footer at the bottom.
