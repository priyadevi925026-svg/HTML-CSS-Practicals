# Assignment 4: Divs, Attributes and a Small Fix

**Course:** HTML and CSS Introduction Lab (BCS352)  
**Institution:** Invertis University, Bareilly  
**Degree:** B.Tech CSE - Second Year  

---

### Aim
Group parts of a page with div elements, add a data attribute, and fix the errors in a broken page.

---

### Tasks
1. Create layout.html with three div blocks: one with the class header, one with the class main and one with the class footer. Put some text in each.
2. Create attributes.html. Give one div the id profile. Inside it, add a paragraph with the attribute data-topic set to hobbies. Write any text in the paragraph.
3. Find and fix every error in the broken page below, then save it as attendance-fixed.html.

```html
<!DOCTYPE html>
<html>
<head>
<title>Attendance</title>
</head>
<body>
<h1>Attendance Report
<p>Asha: 92%<p>
<p>Rohan: 85%</p>
</body>
</html>
```

---

### Sample Expected Output
Three blocks in order: header, main and footer. The paragraph text shows; the data-topic attribute is not visible on the page. The corrected page shows the heading Attendance Report and two lines: Asha: 92% and Rohan: 85%.
