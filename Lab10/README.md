# Assignment 10: CSS Fundamentals

**Course:** HTML and CSS Introduction Lab (BCS352)  
**Institution:** Invertis University, Bareilly  
**Degree:** B.Tech CSE - Second Year  

---

### Aim
Apply CSS in three ways (inline, internal and linked) and use selectors and text styles.

---

### Tasks
1. Create inline-internal.html. In the head, add an internal style block that makes h1 navy and gives the class highlight a yellow background. In the body, add an h1 heading, a paragraph with an inline style that makes its text red, and a paragraph with the class highlight.
2. Create style.css with rules for: all h1 elements (navy), the class note (italic), the id title (underlined), and all p elements (font size 18px and a grey colour).
3. Create linked.html that links style.css. It has an h1 with the id title and two paragraphs with the class note. Write any text in them.

---

### Sample Expected Output
A navy heading, one red paragraph and one yellow paragraph. Once linked, the headings, notes and paragraphs use the new styles. The page is styled only when style.css is in the same folder.
