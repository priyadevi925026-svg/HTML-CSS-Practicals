# Assignment 8: Sign-Up Forms and Choices

**Course:** HTML and CSS Introduction Lab (BCS352)  
**Institution:** Invertis University, Bareilly  
**Degree:** B.Tech CSE - Second Year  

---

### Aim
Make a labelled form with text, email and password fields, choices and a submit button.

---

### Tasks
1. Create signup.html with a form (method post, action thanks.html; you do not need to create thanks.html). Add labelled fields for full name, email and password. Each label must be linked to its field.
2. Create choices.html with a gender question using two radio buttons, Female and Male, and a course dropdown with the options BCA and B.Tech.
3. Create signup-required.html with a full name field and an email field. Make both required, add a placeholder to the name field, and add a Submit button.

---

### Sample Expected Output
Three labelled boxes. The password box hides the characters you type. Only one gender can be selected. The dropdown shows the two courses. Leaving a required field empty shows a validation message.

---

### Submission Guidelines
**Submit:** One .html file per task (and a .css file where used) and a screenshot of the page.  
*Remember to include your Name, Roll Number, and Assignment Number (8) at the top of each file.*
