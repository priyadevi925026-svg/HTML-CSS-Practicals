# Assignment 5: Links and Images

**Course:** HTML and CSS Introduction Lab (BCS352)  
**Institution:** Invertis University, Bareilly  
**Degree:** B.Tech CSE - Second Year  

---

### Aim
Link two pages together and add a picture with alt text.

---

### Tasks
1. Create home.html with the heading Welcome to My Site and a paragraph with a link to portfolio.html. The link text is portfolio.
2. Create portfolio.html with a heading and a link back to home.html. Write any text for the link.
3. Create portfolio-image.html with a heading and a picture from the images folder. Set its width and height to 200 each, and write alt text that describes it. Use the file name your instructor gives you.

---

### Sample Expected Output
Clicking the word portfolio opens the portfolio page. The link goes back to the home page. A 200 by 200 photo under the heading. If the picture is missing, the alt text shows instead.

---

### Submission Guidelines
**Submit:** One .html file per task (and a .css file where used) and a screenshot of the page.  
*Remember to include your Name, Roll Number, and Assignment Number (5) at the top of each file.*
