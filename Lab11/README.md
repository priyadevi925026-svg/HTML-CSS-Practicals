# Assignment 11: Units and CSS Variables

**Course:** HTML and CSS Introduction Lab (BCS352)  
**Institution:** Invertis University, Bareilly  
**Degree:** B.Tech CSE - Second Year  

---

### Aim
Use CSS units and store colours and spacing in variables.

---

### Tasks
1. Create units.html with a div box 200px wide and 40px high, a div box 50% wide and 40px high, and a paragraph of any text at font size 1.5rem. Give both boxes a background colour.
2. Create variables.html with an h1 and a paragraph. In :root, define --main-color as #1d3557, --accent-color as #e63946 and --page-padding as 20px. Use var() for the body colour and padding, and for the h1 colour.
3. Create tokens.css with variables for a primary colour (#1d3557), an accent colour (#e63946), a heading size (2rem) and a spacing value (16px). Use them for the body colour and padding, and for the h1 colour and size.

---

### Sample Expected Output
A 200 pixel box, a half-width box and larger text. The heading uses the accent colour. The text uses the main colour. Linked to a page, tokens.css sets the colours, heading size and spacing.
