# Assignment 12: Box Model, Cards and Scrolling

**Course:** HTML and CSS Introduction Lab (BCS352)  
**Institution:** Invertis University, Bareilly  
**Degree:** B.Tech CSE - Second Year  

---

### Aim
Compare the box sizing types, style a card and make a box scroll.

---

### Tasks
1. Create box-model.html with two boxes (div elements). Both have a width of 200px, padding of 20px and a border of 5px. The first uses box-sizing content-box and the second uses border-box.
2. Create card.html with one card: a div with the class card that has a background colour, a 2px border, rounded corners (border-radius 12px) and padding of 16px. Put an h3 heading and a paragraph inside it.
3. Create scroll.html with a div box of fixed height 120px and overflow set to auto. Put five lines of text inside it as paragraphs, Line 1 to Line 5.

---

### Sample Expected Output
The content-box box is wider than the border-box box. A card with rounded corners, a border and a coloured background. The lines do not fit in the box, so the box can be scrolled.
