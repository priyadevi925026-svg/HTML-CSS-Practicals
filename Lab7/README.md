# Assignment 7: About Me Page

**Course:** HTML and CSS Introduction Lab (BCS352)  
**Institution:** Invertis University, Bareilly  
**Degree:** B.Tech CSE - Second Year  

---

### Aim
Build a short About Me page with semantic tags, an about section and a contact link.

---

### Tasks
1. Create about-me.html with a header (an h1 with your name, and a nav with two links: About to #about and Contact to #contact), an empty main and an empty footer.
2. Add a section inside main with the id about. Give it an h2 heading About me and one paragraph about yourself.
3. Add a paragraph inside the footer with a link to your email address (use mailto: in the href). Give the footer the id contact.

---

### Sample Expected Output
Your name at the top with two links. The middle and bottom are empty initially, then About me heading and paragraph appear under top links. Footer shows clickable email address. The Contact link in top nav jumps to it.

---

### Submission Guidelines
**Submit:** One .html file per task (and a .css file where used) and a screenshot of the page.  
*Remember to include your Name, Roll Number, and Assignment Number (7) at the top of each file.*
