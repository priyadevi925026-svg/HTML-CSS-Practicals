# Assignment 1: Starting a Git Repository

**Course:** HTML and CSS Introduction Lab (BCS352)  
**Institution:** Invertis University, Bareilly  
**Degree:** B.Tech CSE - Second Year  

---

### Aim
Start a Git repository for your lab folder and save your work with commits.

---

### Tasks
1. Create a folder named html-lab and start a Git repository in it with git init. Set your own name and email for this repository only (git config --local). Then show them with git config user.name and git config user.email.
2. Create index.html inside html-lab with one h1 heading, any text. Run git status, add the file and commit it with the message "Add home page".
3. Add a second heading, an h2, below the first one in index.html. Commit it with the message "Add next meeting heading", then run git log --oneline.

---

### Sample Expected Output
Each git config command prints the value you set. git status lists index.html as untracked. The commit line shows 1 file changed. Two commits are listed in git log --oneline, the newest one first.
