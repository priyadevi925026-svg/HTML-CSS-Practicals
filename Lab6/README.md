# Assignment 6: Types of HTML Lists

**Course:** HTML and CSS Introduction Lab (BCS352)  
**Institution:** Invertis University, Bareilly  
**Degree:** B.Tech CSE - Second Year  

---

### Aim
Make a bulleted list, a numbered list with a nested list, and a description list.

---

### Tasks
1. Create shopping-list.html with the heading Shopping List and an unordered list of three items: Notebook, Pen and Bag.
2. Create canteen-menu.html with the heading Canteen Menu, a numbered list of two items: Samosa and Sandwich. Under Sandwich, add a nested numbered list of two items: Cheese and Vegetable.
3. Create faq.html with a description list of two questions: How many books can I borrow? and Is the library open on Sunday? Put each question in a dt element and write an answer in a dd element.

---

### Sample Expected Output
Three bullet points. Two numbered items, and a smaller numbered list under the second one. Two questions, each followed by its answer.

---

**Submit:** One .html file per task (and a .css file where used) and a screenshot of the page.
