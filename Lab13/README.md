# Assignment 13: Flexbox Layouts

**Course:** HTML and CSS Introduction Lab (BCS352)  
**Institution:** Invertis University, Bareilly  
**Degree:** B.Tech CSE - Second Year  

---

### Aim
Lay out a navigation bar, centred cards and cards that wrap, using Flexbox.

---

### Tasks
1. Create nav-flex.html with a horizontal navigation bar (a nav element) of four links: Home, About, Events and Contact. Use display flex for the bar, give it a dark background and make the link text white.
2. Create centred-cards.html with a div (class row) holding three cards (class card) in one row. Each card has an h3 heading (Starter, Standard, Premium) and a paragraph with the price 199, 349 or 499. Use justify-content and align-items to centre the cards in the row.
3. Create wrapping-cards.html with the heading Stationery Shop and four cards in a flex-wrap row: Notebook (price 60), Pen (price 15), Bag (price 350) and Book (price 120). Narrow the browser window to check the wrapping.

---

### Sample Expected Output
A dark bar with four white links side by side. Three cards in one row, centred in the row. On a narrow window, the cards wrap onto new rows.
