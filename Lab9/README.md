# Assignment 9: Tables with Headers and Footers

**Course:** HTML and CSS Introduction Lab (BCS352)  
**Institution:** Invertis University, Bareilly  
**Degree:** B.Tech CSE - Second Year  

---

### Aim
Build a table with a caption, a header, rows and a footer, and add scope attributes.

---

### Tasks
1. Create marks.html with a table that has the caption Marks of Class A. Use thead for the header row (Name, Maths, Science) and tbody for three rows: Asha 78 85, Rohan 64 70 and Neha 91 88.
2. Create marks-average.html with the same caption and header as marks.html, the Asha and Rohan rows (leave out Neha), and a tfoot row called Class average with the average Maths and Science marks of the two students.
3. Create marks-accessible.html with the same caption, header and Asha and Rohan rows, without the footer row. Add scope="col" to each header cell and scope="row" to each name cell.

---

### Sample Expected Output
A table with a header row and three student rows. The footer row at the bottom shows the two averages. The header and name cells carry scope attributes (check in the Elements panel).
